# AI Study Flashcard & Quiz Generator

An AI-powered application designed to help students automatically generate study flashcards and interactive quizzes from their learning materials, making study sessions faster and more effective.

## 🚀 Features

- **Automated Flashcard Generation**: Quickly converts study notes and documents into clear, concise flashcards.
- **Interactive Quiz Creation**: Generates practice quizzes with multiple-choice questions to test your knowledge.
- **AI-Driven Insights**: Uses advanced AI models to extract key concepts and important terms.

## 🛠️ Built With

- **AI Model**: Gemini API
- **Frontend**: HTML / CSS / JavaScript
- **Backend**: Python / Flask

## 📋 Prerequisites

Make sure you have the following installed before running the project:

- [Python 3.x](https://www.python.org/)
- A valid **Gemini API Key**
